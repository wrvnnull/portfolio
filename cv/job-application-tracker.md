## Strategy

### Tier 1 — Apply aggressively
Junior Full-Stack Developer · Junior Software Engineer · QA Automation / Test Automation

### Tier 2 — Apply selectively
Frontend Developer · Backend Developer · Python Automation · AI Automation / LLM Workflow · Technical Support / IT Technical

### Tier 3 — Apply when fit
Web3 technical contributor · Web3 ecosystem · other junior IT engineering roles

### Matching rule
- 60–70% match + other requirements realistic for junior → **RECOMMEND APPLY**
- 20–30% match → **SKIP**
- Core requirement far off → **SKIP**
- Don't reject only for <100%. For junior roles, judge if still realistic to apply.

### CV tailoring (when matched — never invent experience)
- Summary: align to role's primary stack
- Skills ordering: put most relevant first
- Project ordering: lead with most relevant project
- Keywords: mirror JD terms where truthful
- Never fabricate experience to satisfy a JD.
